Data is stored locally in your browser (per form, per record). Use “Export as PDF” inside each form, then choose “Save as PDF” in the print dialog.
Print format follows the BIR spec (RMC 44-2023 / 51-2024): Folio 8.5″ × 13″ bond paper, portrait, official margins built in — set Scale to 100% / Actual size (never shrink-to-fit) and turn headers & footers off.
